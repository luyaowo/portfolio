这是一个售后方向的对话智能体原型：为体外神经刺激设备的患者处理售后咨询、故障排查引导和维修申请，基于本地 Dify Chatflow 与 React 卡片前端实现，业务数据为模拟。

完整案例以 24 屏的形式记录了整个过程：业务与服务流程的整理、知识库与规则的治理（版本合并与口径统一）、LLM 与确定性规则的分工，以及测试与失败修复的过程。
