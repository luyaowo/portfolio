这是一个作品集，汇集了我近几年在产品与设计方向的探索。内容涵盖 UI、插画以及文档体系，展示内容由我独立整理，具体职责与产出会在各项目中说明，其中部分图片由 AI 生成。

由于部分项目涉及商业保密与患者数据，展示中已对敏感信息进行脱敏与简化。

## 序

这份作品集记录了几个阶段：

1. **对移动端的认知阶段**：从研究移动端界面入手，逐渐深入到系统与组件的思考，掌握从基础设计到组件构建的完整文档化过程。
2. **对 B 端设计的认知阶段**：从早期参考界面进行仿照设计，到后来真正承担 B 端交互与页面设计，完成从组件模块学习到任务驱动的交互设计与视觉实现。
3. **对视觉插画与 AIGC 的认知**：以 ChatGPT 作为思维起点，延伸到 Midjourney、DeepSeek 等生成式工具，再回归到 GPT，通过 AIGC 实现视觉表达与创意方案的生成，逐步形成利用对话驱动创意产出的工作方式。
4. **对 3D 设计的认知**：以 Rhino 和 Spline 为基础，探索不同方向的 3D 建模逻辑，研究光照、材质与 UI 设计之间的视觉关系和应用边界。
5. **从认知到实践的交互设计**：通过多轮交互设计项目，整理真实需求与实践文档，在软件设计的上下游中，不断提升对交互逻辑与视觉语言的整体理解。
6. **研究摄影**：作为兴趣的延伸，学习色彩与光影，以及构图对画面叙事的影响。通过拍摄了解摄影底层的内在逻辑与思维延展，尝试不同类型的拍摄风格与设备，体验不同相机、胶片与数码影像的差异，感受镜头之外的观察与思考。

文档较长，感谢你的耐心阅读。慢慢往下翻页，我们一起开启这段旅程。
