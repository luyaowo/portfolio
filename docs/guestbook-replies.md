# 回复访客留言

1. 打开本机的「个人博客文章编辑」应用，启动编辑服务。
2. 在浏览器打开 http://127.0.0.1:4321/about ，找到页面底部的留言。
3. 点击留言下面的「回复」，输入文字后点击「保存回复」。已有回复可以再次编辑。
4. 按原有流程发布网站，回复才会对线上访客可见。

每条留言支持一段可编辑的回复，显示「路遥知玛丽」、日期和回复正文。没有身份标签。访客仍按原有流程提交留言、等待审核。

回复保存在 `src/data/guestbook-replies.json`，发布时应将它与代码一起提交。不要删除已有回复记录。留言列表需要原有留言服务可用。

回复写入接口只在开发模式下接受本机、同源请求，生产环境一律拒绝写入；生产页面不显示编辑按钮。不需要新增账号或修改数据库。
